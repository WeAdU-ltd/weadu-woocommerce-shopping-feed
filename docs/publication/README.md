# Publication kit: WeAdU Shopping Feed Check (WooCommerce)

Texts for the WeAdU team member who posts by hand. Nothing here is posted automatically.

| File | Content |
| --- | --- |
| `listing-en.md` | WordPress.org listing texts in English (the source of truth is `weadu-shopping-feed/readme.txt`). |
| `listing-fr.md` | French translation of the listing, for reference and for the French translation of the plugin page. |
| `post-en.md` | Short message for the Woo Community Slack, channel #self-promotion, ready to copy. |
| `post-fr.md` | French version of the message. |
| `instructions-maricar.md` | Where to post, the rules to follow, and how to handle replies (English and French). |
| `checklist.md` | What has to be done before anything is posted. |

Do not post anything until the WeAdU team confirms the plugin is live on WordPress.org and sends you the link. Replace `LINK` with that link.
